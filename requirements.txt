# ==============================================================================
# vllm-iluvatar runtime requirements -- SINGLE SOURCE OF TRUTH.
#
# Mirrors vllm/requirements/common.txt + vllm/requirements/cuda.txt with the
# iluvatar-only overrides described below.  This file feeds BOTH:
#   * ``install_vllm_iluvatar.sh`` (runtime install), and
#   * the wheel's ``Requires-Dist`` via ``setup.py:get_requirements()``.
# It supersedes the former ``requirements/common.txt``, which had drifted from
# this file (ray / diskcache / numba / loguru / pycountry / apache-tvm-ffi were
# only here; llguidance / xgrammar / compressed-tensors were only there).
#
# Iluvatar deltas vs. upstream vllm/requirements/*.txt:
#
#   * ``numpy`` is pinned ``<2``.  CoreX torch is built against the NumPy 1.x
#     C ABI, but its wheel METADATA declares no numpy dependency at all, so
#     pip cannot infer the bound -- it has to be stated here (and mirrored in
#     the image's PIP_CONSTRAINT file).
#   * ``opencv-python-headless`` is held at 4.11.0.86.  Upstream asks for
#     >= 4.13.0, but every release from 4.13 on declares ``numpy>=2``, which
#     is unsatisfiable against the pin above.
#   * ``mistral_common`` is pinned without upstream's ``[image]`` extra: that
#     extra resolves opencv on its own and would fight the pin above.
#   * ``compressed-tensors`` is held at 0.15.0.1 (upstream moved to 0.17.0).
#   * ``apache-tvm-ffi`` is a floor rather than upstream's ``==0.1.10`` pin;
#     it is pulled in by xgrammar.
#   * All torch / torchvision / torchaudio / torchcodec / nvidia-* /
#     flashinfer / nvtx / quack / cutlass-dsl / tokenspeed / humming entries
#     from cuda.txt are dropped -- CoreX platform, not NVIDIA.
#   * ``tilelang`` and ``fastsafetensors`` are also dropped.  Both are guarded
#     by optional-import shims upstream, and the iluvatar MHC path uses
#     ixformer's ``ds4_mhc_pre_*`` kernels rather than the tilelang ones.
#   * ``ray`` and ``diskcache`` are additions -- upstream 0.26.0 no longer
#     lists ray in common.txt, and diskcache backs the outlines disk cache.
#   * ``loguru`` / ``pycountry`` are transitive gap-fillers, kept explicit so
#     the ``--no-deps`` install path in install_vllm_iluvatar.sh does not
#     leave them out.  Extend that group (not the --no-deps list) when a new
#     "X requires Y, which is not installed" surfaces at runtime.
# ==============================================================================
