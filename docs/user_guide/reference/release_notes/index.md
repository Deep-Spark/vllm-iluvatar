# 版本说明



!!! note "说明"
    本页从 vLLM v0.27.1 起整理版本说明，早于该版本的历史信息不再赘述。

本页汇总 `vllm-iluvatar` 与天数 vLLM 的配套版本说明。部署或升级前，请先确认使用的 vLLM 本体、`vllm-iluvatar` 插件、镜像、driver 和 CoreX runtime 来自同一次发布。

## 已发布版本



| 版本 | 状态 | 适用架构 | 说明 |
| --- | --- | --- | --- |
| [vLLM v0.27.1](vllm_v0.27.1.md) | 已发布 | x86_64；aarch64 | 首个 out-of-tree plugin 架构版本，x86_64 和 aarch64 均已发布。 |

v0.27.1 是当前最新的发布版本。

## 阅读建议



- 首次部署时，打开侧边栏的「安装」，按其中页面确认镜像和 driver。
- 升级或替换模型权重前，阅读对应版本说明中的量化、环境变量和启动参数变化。
- 多版本共存或排查问题时，以具体版本页面中的版本配套关系为准。
