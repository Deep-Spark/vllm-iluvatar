# ==============================================================================
# vllm-iluvatar runtime requirements  (mirror of vllm/requirements/common.txt +
# vllm/requirements/cuda.txt, with the iluvatar-only overrides described below).
#
# Not used by the wheel's METADATA (setup.py strips Requires-Dist by default so
# `pip install <wheel>` doesn't fight the CoreX SDK stack).  ``install_vllm_
# iluvatar.sh`` picks this up after the wheel install; see that script for the
# full install order, including the ``--no-deps`` pins that pip's requirements
# parser cannot express inline.
#
# Iluvatar deltas vs. upstream vllm/requirements/*.txt:
#
#   * ``numpy`` is commented out below -- installed out-of-band by
#     ``install_vllm_iluvatar.sh`` (needs a manual ``<2`` pin to match
#     CoreX torch's NumPy 1.x C ABI).
#   * ``mistral_common`` / ``opencv-python-headless`` / ``compressed-tensors``
#     are commented out and installed with ``--no-deps`` by the shell script
#     (their upstream dep specs would otherwise force pip to downgrade
#     CoreX-verified packages such as numpy / pillow / requests).
#   * ``xgrammar`` is also ``--no-deps`` installed: it declares
#     ``torch>=1.10.0`` and pip's resolver would drag in NVIDIA ``nvidia-*``
#     wheels (~1.5 GB) because it cannot see the CoreX torch already staged
#     at ``TARGET_DIR/lib/python3/dist-packages``.
#   * ``llguidance`` is also ``--no-deps`` installed: developer hosts get it
#     from CoreX SDK's Python bundle, but the ``-t TARGET_DIR`` install path
#     used for packaging leaves pip blind to that bundle, so vLLM's
#     ``import llguidance`` at guidance-backend module load fails without an
#     explicit install here.
#   * All ``nvidia-*`` / flashinfer / torch cuda.txt entries are dropped
#     (CoreX platform, not NVIDIA).
#   * A "transitive gap-fillers" section near the bottom (e.g. ``loguru``,
#     ``pycountry``) explicitly lists the deps that the --no-deps quartet
#     would normally have brought in but that vLLM actually imports at
#     module load time. Extend that section (not the --no-deps list) when
#     a new "X requires Y, which is not installed" surfaces at runtime.
# ==============================================================================
